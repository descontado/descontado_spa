# descontado_spa

Site institucional estático e responsivo do Descontado, sem etapa de build. A configuração de preview
local/deploy está descrita no README; a porta de preview é `4173`.

## Comandos

- `npm run lint`: verifica o projeto.
- Não há scripts `dev`, `build` ou `start` no `package.json`; confira o [`README.md`](./README.md)
  antes de escolher um servidor local ou publicar.

## Regras compartilhadas

No workspace, consulte [`../../.claude/CLAUDE.md`](../../.claude/CLAUDE.md) e as regras aplicáveis
em `../../.claude/rules/`, especialmente frontend, documentação/acessibilidade e Git. Se este
repositório estiver clonado sozinho, consulte a [fonte canônica no workspace](https://github.com/descontado/workspace/tree/develop/.claude).
As regras com `paths` são relativas à raiz do workspace e não são duplicadas neste projeto.
